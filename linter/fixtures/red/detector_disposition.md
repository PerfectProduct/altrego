# RED · detector_disposition

Отчёт исполнителя принят, гард введён; вердикт опирается на одно предсказание.

## Что сделано

Пакет вводит новый чекер `policy_claim`: он краснеет на утверждении об удалении
записи, не подтверждённом ногой теста. Предсказание — краснеет на всех четырёх
местах публичной политики; принимаю по этому предсказанию.

## Второй детектор того же пакета

Вводит ещё одну новую ногу `policy_scope` — периметр гарда по перечню файлов.

- **Предсказанная диспозиция:** 2–4.

## Ваши действия

1. Прогнать гард на публичной политике и прислать вывод целиком:

```bash
npm run guard:policy -- --report /tmp/policy-guard.json; echo "код выхода: $?"
```

Ожидаемо: четыре красных места — фактический вывод на предмете, измерено оркестратором 2026-08-31.

**Конец хода:** нужно слово владельца — принять гард либо назвать расхождение.
