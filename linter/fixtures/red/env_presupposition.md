# RED · env_presupposition

Провенанс: `00-system/canon-corrections-register.md` §B, строка «Исполнимость
shell-блока», вопрос 2 (предпосылки о среде измеряются), К2/К3 — рецидив
2026-08-31, счёт 3. По лестнице лечения §B третий рецидив закрывает дописывание
текста: правило снимается или заменяется механикой, не зависящей от памяти
оркестратора. Этот чекер и есть такая механика, а блок ниже — предмет, на
котором она обязана краснеть.

```bash
pip install --user pyyaml
gcloud run services update theygrow-web --region europe-west1 --min-instances 1
adb -s R58M12ABCDE shell input keyevent 82
```

Каждая из трёх строк адресуется к состоянию среды по имени, взятому не из
измерения этого хода: установка вне venv в среде PEP 668, имя сервиса Cloud Run
и серийник устройства. Провал такого блока неотличим от отсутствия предмета —
владелец видит отказ инструмента, а не ответ про предмет.

Тот же класс отказа на правах токена (реестр §B, 2026-09-03/04): файл workflow
отправлен в индекс и пушится, а право `workflow` у токена не измерено; ниже
право добавляется, но текущий набор прав опять же не прочитан.

```bash
git add .github/workflows/ci.yml
git commit -m "гейт: лимит прогона"
git push
gh auth refresh -s workflow
```

Тот же класс на чтении по сети и на переустановке зависимости (ADR-054, NB-45 и
NB-44): за редиректом следуют, не называя конечного адреса, а зависимость ставится
подвижным указателем вместо неизменяемой редакции.

```bash
curl -sSL https://example.invalid/policy.json -o /tmp/policy.json
curl --location https://example.invalid/policy.json -o /tmp/policy.json
curl -fsSL https://example.invalid/install.sh | bash
curl -sSL -X POST https://example.invalid/hook -d @/tmp/payload.json
curl -sSL --max-redirs 3 https://example.invalid/policy.json -o /tmp/policy.json
npm install express
```

Та же пара форм в другой оболочке. Маркера над оградой нет намеренно: область
задаётся списком языков, а не маркером.

```powershell
Install-Module Pester
winget install Git.Git
```
