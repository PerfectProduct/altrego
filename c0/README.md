# C0: outcome-oracle experiment

Work in progress. No measured builder attempt has started.

The owner authorized one continuous C0 task, a local branch and local commits.
The comparison is Codex CLI alone versus the same CLI with the full applicable
Altrego process. Both use the existing ChatGPT subscription, with no additional
spend. Five tasks and ten main attempts are required. Push, merge and publication
remain with the owner.

`intake-policy-v1.json` freezes passive input criteria before selected requirement
documents are read. It is an experimental instrument, not a new canonical intake
rule. Its acceptance result cannot select tasks or change their requirements.

Recovery evidence is local and ignored by git under `reports/c0-recovery/`:
`reading-ledger.json`, `queue-source-comparison.json`, `mcp-escalated.json`,
`pytest-unsandboxed.txt`, and the append-only Filesystem MCP transport log.
Vault snapshots are reading evidence only and must not enter commits or builder
workspaces. Source documents remain authoritative in the vault.

`sampling-policy-v1.json` and `selection-v1.json` freeze the Python-only sample
and alternating arm order before reading its requirements. `source-review.md`
records the preliminary external-methods review and evaluator findings.

Before measured execution, remaining prerequisites include the embedded-source
license inventory, builder/evaluator access isolation, a separate technical
smoke, and the complete immutable campaign manifest. No result may be inferred
from preparation checks.
